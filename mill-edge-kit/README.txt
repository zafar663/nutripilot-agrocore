AgroCore Prime — mill-edge (this mill only)

This zip is for one mill. Do not share it.
config.json contains this mill’s private address.

Windows
1. Unzip this folder.
2. Double-click INSTALL.
3. PLC batch files go in the watch folder.
   Truck tickets go in the weighbridge folder.
   Lab files go in the lab folder.
   Pellet and energy files go in the process folder.
   Load-out files go in the dispatch folder.
4. Refresh Mill IQ. The mill-edge chip turns green.

The window closes. mill-edge keeps running.

Mac
1. Unzip, then double-click INSTALL.command.
2. Use the same folder names inside the inbox.
3. Refresh Mill IQ.
